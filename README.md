# 精灵物语技术支持

## 常见问题

**天气无法刷新**  
请检查网络后下拉页面或点击右上角刷新。Open-Meteo 暂时不可用时，App 会显示明确标记的演示天气。

**如何更换城市**  
打开底部“云间小筑”，选择加号可以选择不同的区域查看天气。
